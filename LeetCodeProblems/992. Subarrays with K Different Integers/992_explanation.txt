1) (time limit) we make every possible subarray that has k or less unique elements,
  meaning if nums = 1,2,1,2,3 we make every subarray starting from 1 then 2 then 3 and so on
  so it would be [1], [1,2], [1,2,1], [1,2,1,2], we keep track of how many unqiue elements we have with a hash map or 
  a frequency array, every subarray that has unique elements  == k, increments the total count by 1.
  once we reach a subarray that start from 1 that has more than k unique elements , we know that we can move onto making
  new subarrays starting from 2 then and so on.
  
  we do this approach with 2 loops, first i = 0, second j = i, every time j increments, it the hashmap, does this element
  already exist? if it doesnt it increments the count of uniques, if it does then we dont need to do anything, and j++
  once reach j that makes unique > k, we break and i = 1 , and start the second loop again.
